# Доставка History

Сервис доставки еды и продуктов из халяль-заведений. Основан на каталоге [Halal Tracker](https://halaltracker.zaganoid8.chatgpt.site/tracker/).

## Что умеет

- Выбор города: Махачкала и Каспийск. Список городов, где работает доставка, задаётся в `ACTIVE_CITIES` в `app.js`; заведения других городов (Дербент, Нальчик, Сочи, Хасавюрт) остаются в данных, но на сайте скрыты.
- Интерфейс по образцу сервисов доставки вроде Яндекс Маркет Доставки: шапка с адресом, поиском и корзиной; плитки категорий; карточки заведений; страница заведения с меню разделов, окном блюда и корзиной справа (на телефоне — плашка снизу). Логотипы и фирменный цвет Яндекса не используются.
- Заведения сеткой или на карте 2ГИС. Поиск по заведениям и блюдам, категории (рестораны, фастфуд, кофейни, мясные магазины, доставки) и кнопка «Рядом со мной», которая сортирует места по расстоянию.
- Страница заведения: меню по разделам, поиск в меню, окно «Информация» со ссылками «Открыть в 2ГИС» и «Маршрут в 2ГИС».
- Корзина: в одном заказе — блюда только из одного заведения. Минимальная сумма заказа — `DELIVERY.minOrder` в `app.js`.
- Доставка — по образцу службы «Такси Анжи» (см. ниже): адрес выбирается поиском или пином на карте, стоимость считается по маршруту, после заказа — экран отслеживания курьера.
- Отдельная услуга «Курьер»: забрать в заведении из каталога и привезти по адресу. Точку A можно выбрать только из заведений каталога (список или карта), точка B — любой адрес.
- «Мои заказы»: ход заказа, отправка заказа заведению в WhatsApp, «Поделиться», отмена, повтор, оценка курьера.
- Приложение водителя — `driver/` (ссылка «Для водителей и курьеров» внизу сайта), см. ниже.

## Доставка

Пока тариф один — «Курьер» (`TARIFFS` в `delivery.js`), по образцу «Такси Анжи». Он действует и для доставки из меню заведения, и для услуги «Курьер»:

| Тариф | Подача | За км по городу | За км между городами | Пробки | Ожидание | Курьер к двери |
|---|---|---|---|---|---|---|
| Курьер | 100 ₽ | 28 ₽ | 33 ₽ | +7 ₽ за лишнюю минуту | 3 мин бесплатно, затем 7 ₽/мин | +50 ₽ |

- Цена = (подача 100 ₽ + км × 28 ₽, или × 33 ₽, если точки в разных городах — Махачкала ↔ Каспийск, + надбавка за пробки) × динамический коэффициент, с округлением до 10 ₽. Коэффициент (`surge` в `delivery.js`) пока 1 — его зададим позже; когда он больше 1, в расшифровке цены появляется строка «Повышенный спрос». Сверху — выключатель «Курьер к двери»: курьер поднимется и отдаст в руки, +50 ₽ (`doorFee`). По умолчанию выключен, выбор запоминается в браузере; опция видна водителю и попадает в сообщение заведению.
- Надбавка за пробки — 7 ₽ (`jamPerMin`) за каждую полную минуту, потерянную в пробках. Минуты берутся у Яндекс Карт: время маршрута на машине с текущими пробками минус время без пробок. Для этого нужен ключ `yandexMapsKey` в `config.js` (см. «Пробки: Яндекс Карты»). Без ключа или если Яндекс не ответил за 6 секунд — по маршруту 2ГИС: насколько он дольше, чем при средней скорости 30 км/ч (`freeKmh`).
- Ориентир — «Такси Анжи», тариф «Курьер» (подача 100 ₽ + 28 ₽/км). Его цены одной поездки меняются со временем: Meat Lavka → Малыгина 45 стоила 240, 210, 160 ₽ — динамическая надбавка Анжи зависит не только от пробок, поэтому точно её не повторяем.
- Расстояние — по маршруту 2ГИС (Routing API); если он недоступен — по прямой × 1,35. Город точки берётся из адреса 2ГИС и из карточки заведения.
- Адреса — 2ГИС Каталог: подсказки, адрес по точке на карте. «Мои адреса» (Дом, Работа и последние) хранятся в браузере.
- Отслеживание: точки A и B, маршрут, курьер на карте, ход заказа (поиск → едет за заказом → забирает → везёт → доставлен), время прибытия, оценка после доставки.
- Если в момент заказа водитель на линии в приложении, заказ уходит ему (`dispatchMode: 'driver'`), и клиент видит настоящие статусы, имя, транспорт и положение водителя. Если никого нет на линии, заказ ведёт демо-курьер: ход считается по времени (`timeline` в `delivery.js`).

## Приложение водителя

Открывается по адресу `/driver/`. Пока сервера нет, связь с сайтом клиента идёт через `localStorage` этого браузера (`bus.js`), поэтому **тестировать нужно в одном браузере**: сайт клиента в одной вкладке, приложение водителя — в другой.

1. Заполните профиль (имя, телефон, транспорт, машина и номер) и нажмите «На линии».
2. В соседней вкладке оформите заказ на сайте — он появится у водителя: откуда, куда, расстояние, оплата, заработок. «Принять» или «Пропустить».
3. Этапы: «Я на месте» (таймер ожидания: 3 мин бесплатно, дальше 7 ₽/мин; у заведения ожидание бесплатное) → «Забрал заказ» → «Доставил» → «Получите с клиента N ₽».
4. Кнопки «Навигатор 2ГИС», звонок клиенту, получателю и заведению, «Отказаться» (заказ вернётся в поиск).
5. Положение: «Демо-движение» — водитель едет по маршруту сам, с ускорением ×1/×5/×20; «GPS» — настоящая геопозиция телефона.
6. Заработок за сегодня и история — кнопка с суммой в шапке.

Чтобы водитель и клиент работали с разных устройств, нужен сервер: тогда заменяется только `bus.js`.

## Пробки: Яндекс Карты

1. Получите ключ в [Кабинете разработчика Яндекса](https://developer.tech.yandex.ru): «Подключить API» → «JavaScript API и HTTP Геокодер». В настройках ключа укажите адрес сайта.
2. Впишите его в `config.js`: `yandexMapsKey: 'ваш-ключ'`.

Сайт запрашивает у Яндекса только маршрут A → B при расчёте цены; карты по-прежнему 2ГИС.

## Карта 2ГИС

Карта работает на [2ГИС MapGL JS API](https://docs.2gis.com/ru/mapgl/overview). Для него нужен ключ:

1. Зарегистрируйтесь на [platform.2gis.ru](https://platform.2gis.ru) и создайте ключ для MapGL JS API.
2. Впишите его в `config.js`: `twoGisKey: 'ваш-ключ'`.

Пока ключа нет или если 2ГИС не загрузился, карта показывается на OpenStreetMap (Leaflet лежит в `vendor/leaflet/`). Ссылки «Открыть в 2ГИС», «Маршрут в 2ГИС» и точка доставки в заказе ведут в 2ГИС и работают без ключа.

## Запуск

Сборка не нужна. Достаточно запустить любой статический сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Ограничения текущей версии (MVP)

- Сервера нет. Корзина и заказы хранятся в `localStorage` браузера клиента.
- Заведение получает заказ, когда клиент нажимает «Отправить заведению в WhatsApp». Сообщение заполняется автоматически.
- Приложение водителя связано с сайтом только в пределах одного браузера, пока нет сервера. Без водителя на линии заказ ведёт демо-курьер.
- Меню есть только у Haba и Meat Lavka (у Meat Lavka — демонстрационное). У остальных заведений на странице — «Меню пока нет», контакты и кнопка «Доставка» (открывает форму «Курьер»); заказать из них через корзину нельзя.
