# Халяль Доставка

Сервис доставки еды и продуктов из халяль-заведений. Основан на каталоге [Halal Tracker](https://halaltracker.zaganoid8.chatgpt.site/tracker/).

## Что умеет

- Выбор города: Махачкала и Каспийск. Список городов, где работает доставка, задаётся в `ACTIVE_CITIES` в `app.js`; заведения других городов (Дербент, Нальчик, Сочи, Хасавюрт) остаются в данных, но на сайте скрыты.
- Заведения на карте 2ГИС и в списке. Есть поиск, фильтр по категориям (рестораны, фастфуд, кофейни, мясные магазины) и кнопка «Рядом со мной», которая сортирует места по расстоянию.
- Страница заведения с меню, разбитым на разделы, и ссылками «Открыть в 2ГИС» и «Маршрут в 2ГИС».
- Корзина: в одном заказе — блюда только из одного заведения. Минимальная сумма заказа и стоимость доставки задаются в константе `DELIVERY` в `app.js`.
- Оформление заказа: имя, телефон, адрес, геопозиция, время доставки, способ оплаты, комментарий.
- «Мои заказы»: статус заказа, отправка заказа заведению в WhatsApp, звонок, копирование текста, отмена и повтор заказа.

## Карта 2ГИС

Карта работает на [2ГИС MapGL JS API](https://docs.2gis.com/ru/mapgl/overview). Для него нужен ключ:

1. Зарегистрируйтесь на [platform.2gis.ru](https://platform.2gis.ru) и создайте ключ для MapGL JS API.
2. Впишите его в `config.js`: `twoGisKey: 'ваш-ключ'`.

Пока ключа нет или если 2ГИС не загрузился, карта показывается на OpenStreetMap (Leaflet лежит в `vendor/leaflet/`). Ссылки «Открыть в 2ГИС», «Маршрут в 2ГИС» и точка доставки в заказе ведут в 2ГИС и работают без ключа.

## Запуск

Сборка не нужна. Достаточно запустить любой статический сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | Каркас страницы |
| `style.css` | Стили в палитре Halal Tracker |
| `config.js` | Настройки: ключ 2ГИС |
| `map.js` | Карта: 2ГИС MapGL или запасной Leaflet + OpenStreetMap |
| `app.js` | Роутинг (`#/`, `#/place/:id`, `#/checkout`, `#/orders`), каталог, карта, корзина, заказы |
| `data/places.js` | 84 заведения из Halal Tracker: 79 мест и 5 мясных магазинов из раздела поставщиков |
| `data/menus.js` | Меню: шаблоны по категориям; настоящее меню заведения добавляется в `byPlace[id]` |
| `data/menus-yandex.js` | Настоящие меню 12 заведений (Гамач Бургер, Chicago Pizza, Урбеч, Ростикс, People Coffee), выгружены с Яндекс Еды 09.10.2026 |
| `data/menus-manual.js` | Меню, добавленные вручную из материалов заведений (Haba — из Instagram) |

## Ограничения текущей версии (MVP)

- Сервера нет. Корзина и заказы хранятся в `localStorage` браузера клиента.
- Заведение получает заказ, когда клиент нажимает «Отправить заведению в WhatsApp». Сообщение заполняется автоматически.
- Статусы заказа меняются по таймеру, чтобы показать, как это будет выглядеть.
- Меню с Яндекс Еды есть у 12 заведений, у остальных — демонстрационные. Цены на Яндекс Еде могут отличаться от цен в заведении.

## Следующие шаги

1. Бэкенд и база данных: заказы, меню и заведения (например, Supabase, Firebase или Node + PostgreSQL).
2. Кабинет заведения: редактирование меню и цен, приём заказов, смена статусов.
3. Уведомления заведению о новом заказе (Telegram-бот или WhatsApp Business API).
4. Онлайн-оплата (ЮKassa, CloudPayments).
5. Зоны и стоимость доставки по расстоянию, приложение для курьеров.
